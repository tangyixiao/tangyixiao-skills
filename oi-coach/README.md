# OI 自适应教练 · oi-coach

给 AI 用的信息学竞赛教学 skill，覆盖 OI、CSP、NOIP 的新知识学习、分级提示、代码批改与赛后复盘。

目标是让学生理解算法为什么会这样设计，并逐渐能自己读题、建模、实现和检验。它同时约束教学方式和学习记录：一份完整的讲解、一次旧题 AC、助手跑通的程序，都不能自动记成学生已经掌握。

## 它怎样教

从题目的输入、操作、目标和约束开始，用小例子尝试朴素做法。哪里太慢，哪里不成立，观察到了什么性质，才决定怎样优化。概念名称、公式、证明和实现接在这个过程之后。

根据真实作答切换方式：有必要基础就引导发现；缺基础或卡住时直接讲透；认为已经会了，就停止提示，用完整的新任务检验。不会把一段解释拆成十几个反问，也不会把每课独立实现设成继续学习的门槛。

它还会：

- 根据已有教材、老师要求与学习记录确定起点，不凭历史 AC 推测当前水平。
- 尊重“只要提示”的边界，按请求逐级提供帮助。
- 代码批改先定位首要错误，结合边界和反例解释；能运行时再报告实测结果。
- 区分讲过、当堂解释、提示后完成、独立实现、延迟保留与陌生迁移。
- 使用可视化或配音时保留同源文字，检查画面与讲解是否真的对应。
- 将进度留在用户已有的记录里，便于跨设备继续。

## 安装到 Codex

可以直接对 Codex 说：

> 安装这个 skill：https://github.com/tangyixiao/oi-coach

也可以把本仓库克隆到自己的用户 skills 目录。通常是 `~/.codex/skills/oi-coach`；若自定义了 `CODEX_HOME`，则放在对应的 `skills/oi-coach` 下。Windows PowerShell 的默认目录示例：

```powershell
git clone https://github.com/tangyixiao/oi-coach.git "$env:USERPROFILE/.codex/skills/oi-coach"
```

目标目录已有文件时，先检查已有内容与改动，选择更新或合并，保留原记录。安装后开启新会话并使用 `$oi-coach`。其他支持 `SKILL.md` 的代理可按各自的技能目录规则安装。

## 怎么使用

开始学习：

> 使用 $oi-coach。我想学线段树。先看我提供的讲义和学习接续，确定今天的目标。我有基础时引导我推；完全不会时直接示范。按完整模型讲，不要反复考零碎填空。

只要提示：

> 使用 $oi-coach，提示1。我已经写出了暴力，卡在怎样减少重复计算。先不要告诉我算法名。

批改程序：

> 使用 $oi-coach。保留我的写法，先找最主要的问题，给一个能说明错误的反例，再解释最小修改。没有运行就明确说没有运行。

收工与接续：

> 使用 $oi-coach，收工。把我今天实际答过、写过、验证过的内容与助手提供的帮助分开记录，留下下一次从哪里继续。

只需提供与当前学习有关的教材、题目、自己的尝试或已有记录。首次使用不要求先建立完整档案；文件化记录按实际需要增加。

## 文件结构

```text
oi-coach/
├── SKILL.md                         核心流程、提示与掌握规则
├── agents/openai.yaml               Codex 显示信息
├── references/adaptive-teaching.md   教学蓝本、自然语言与动态教学协议
├── examples/teaching-cases.md        课堂片段与行为检查案例
├── README.md
└── LICENSE
```

这是教学指令与参考资料，不是独立运行的教学应用。它不内置 TTS、编译器或视频渲染器；是否使用这些工具取决于当前环境和任务授权。技能规则及其检查案例不能证明已经改善某位学生的长期成绩，实际效果仍需通过独立作答、延迟复测和迁移观察。

## 修改与贡献

欢迎用具体教学失败案例提出改进：学生在哪一步卡住，原讲解省掉了什么，修改后怎样检验。提交示例前请去掉学生身份、私人作业记录和凭据。修改入口规则时，同时检查它是否与提示边界、完整模型教学和证据记录冲突。
