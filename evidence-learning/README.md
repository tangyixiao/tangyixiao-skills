# Evidence Learning · 用实践证据改进学习

一套面向高中学习、信息学竞赛和 AI 辅助学习的方法手册，以及可以安装的 `evidence-learning` skill。

教学时先用教材备课，再按学生真实回答在引导发现、直接讲透、独立考核之间切换。讲清困难怎样出现、观察到了什么、为什么能据此优化；自然语言不只是给教材换一种口语说法。

需要课堂对话时，可让不同人声的虚拟同学提出疑问、尝试或预测，再由教师接着演示；明确这是示范对话，不把角色台词当成真实学生的能力证据。

从一个真实卡点开始，选择合适的讲解与练习，独立完成，再在之后检查是否仍然会用。学习时长、资料数量和当堂熟悉感可以记录，但不能代替这些证据。

本项目由个人学习资料中的方法整理而来，初版日期为 **2026-10-14（Asia/Shanghai）**。它公开可复用的流程，不公开个人训练档案。当前版本说明了采用哪些规则，尚无足够的个人长期对照数据证明整套方法有效，也不承诺提分。

## 今天可以这样用

1. 选一个自己确实不会或做不稳的问题，写清本次目标，例如“解释这个公式的条件，并独立完成一个变式”。
2. 判断卡点。没学过就先用一个清楚范例建立概念；已有基础就先尝试，再按需请求提示。
3. 根据本次目标安排自己解释、完整应用或实现；检验独立能力时关掉参考，核对答案、边界和依据。用了帮助就如实记录。未完成全部验证不等于禁止继续学习。
4. 只留下错误原因、检验结果和下次起点；独立完成后按需要安排延迟复测。

只需要十分钟时，就缩小任务。学校课程、作业、休息和老师当天要求先进入同一份时间预算。不要额外叠加本项目的整套流程。

## 现在与将来怎么区分

- **当前规则**：已经写入学习安排、教练约定或接续流程的方法；实际执行和效果仍须分别记录。
- **个人偏好**：例如较长可用时段内上午、下午各集中一个专题。其他人可以调整，不是普遍最优方案。
- **未来候选**：有使用条件和检验办法，尚未确认采用或有效；按需要选择一种小规模尝试。
- **能力结果**：只由真实独立表现、延迟复测与变式证据支持，不从方法是否写进计划反推。

## 安装与调用

仓库根目录就是一个完整的 skill，包含 `SKILL.md`、`references`、`assets` 和 `agents`。下载或克隆后，将该目录作为 `evidence-learning` 放入所用工具的用户 skill 目录，保留配套文件。例如本机 Codex 的常见位置为 `~/.codex/skills/evidence-learning`；实际以工具配置为准。请勿把嵌套 `.git` 目录同步进个人 skill 合集。

发现该 skill 后，可以这样请求：

```text
使用 $evidence-learning，按我的教材开始教学。
先检查必要前置；有思路就引导我推，没有基础就直接示范。
讲清为什么想到这一步，按完整问题推进，不要连续追问零碎填空。
```

```text
使用 $evidence-learning，根据我已有的学习记录安排下一个学习块。
我今天只有 40 分钟，先判断卡点，只给第一层提示。
```

```text
使用 $evidence-learning，帮我比较最近几次无提示复测。
不要把看过题解的旧题计入陌生题正确率，最后给出一个可验证的调整。
```

```text
使用 $evidence-learning，为高中下一阶段提出一个两周方法试验。
区分已有流程与未来候选，并把文化课、信奥、休息放在同一份预算中。
```

Skill 可自行完成方法诊断、学习块设计、记录与复盘；不依赖其他 skill、私人资料库、固定盘符或某个 AI 服务。具体题目的知识结论仍须按教材、题面或可靠资料核对。

## 维护方式

按“提出具体问题 → 核对资料 → 小范围尝试 → 留下无辅助表现 → 决定保留、调整或停止”更新方法。新增研究写明对象、结果与边界；个人尝试不写成因果证明。没有正在运行的自动更新、抓取或提醒任务。

适合贡献：更清楚的使用条件、可复用模板、指出错误的来源和匿名的真实试验。请勿提交学校内部材料、个人成绩档案、完整题包、第三方文稿或账号凭据。
