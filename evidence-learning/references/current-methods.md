# 当前学习方法

整理日期：2026-10-14。这里的“当前”表示方法已纳入已有计划、教练规则或接续记录，**不表示已经完整执行，更不表示已证明个人效果**。来源背景见 [来源与边界](sources.md)。公开版不携带个人成绩、题目提交和当天学习档案。

## 1. 先找真实卡点，再选学习方式

不要用“这科不行”结束诊断。改问：概念不知道，条件看不出，模型选错，步骤写不出，还是没有检查？先看最近作业、试卷或短任务的实际表现。

优先级由真实损失、反复出现程度、修补成本和知识依赖共同决定。不照搬别人固定的章节收益排名。一次只补一个主要缺口；新任务需要同时补多个前置时，先缩小。

任务写成“今天能独立解释什么、完成什么、用什么检验”。对陌生内容，先有范例和讲解；对已经学过的内容，先回忆再决定补哪一步。两者不使用同一套等待题解的计时规则。

## 2. 集中学练，预留纠错和生活时间

可用时间较长时，沿用上午、下午各集中一个专题的偏好，专题内连续学、练、验证。只有一小段时间时就做一个微任务，不照搬全天安排。

一个普通学习块可以是：前置回忆 → 小范例或独立尝试 → 自己解释 → 撤去参考练习 → 检查与订正。预算来自实际余量，没有统一最优分钟数。目标提前完成可以结束，进度慢先缩小范围。

学校模拟和集中订正可替换个人学习块；听讲、作业和休息都计入当天安排。不要在完整比赛后再叠加原本全天的新课。周计划先扣除固定任务，仅预排部分余量，给临时要求和休息留位置。

## 3. 文化课：把条件、过程和材料依据讲清楚

| 学科任务 | 一个可以直接用的流程 | 完成检查 |
|---|---|---|
| 数学 | 诊断一个题型 → 核对定义和适用条件 → 对照一例 → 合上解答重做 → 小变式 | 条件为什么够用；换条件后还能不能用；定义域与特殊值 |
| 物理、化学等 | 复述情境 → 画图或表示过程 → 选择规律 → 列式或解释 → 检验 | 规律条件、单位、符号、数量级、实验结论与证据 |
| 英语 | 遮住答案回忆旧词 → 在语境中辨义 → 听读或短输出 → 订正 | 从“认得”转向能回忆、辨义与使用；阅读定位原文依据 |
| 语文 | 课内知识回忆 → 阅读定位材料 → 说明判断 → 修改一处表达 | 背诵实际默写；阅读观点有材料依据；作文论点与素材相连 |
| 历史、地理、政治等 | 回忆结构 → 比较概念或过程 → 用材料题检查 → 订正 | 区分事实、材料、推断和观点；因果关系不是简单罗列 |

这些是本项目的实践建议，不是各科统一评分标准。教材、老师与学校的题目要求优先。写作修改保留本人想法和表达，不编经历，不把 AI 成文冒充本人独立作业。

英语若已有词汇复习表，就继续使用其有效间隔。新词、旧词、听读与输出共用预算；时间紧时先评估减少新内容，不能把一份词汇计划再加在另一张满额周表之外。

## 4. 信奥：先分四种训练用途

| 用途 | 怎么做 | 如实记录什么 |
|---|---|---|
| 学新知识 | 知道用途与前置；学习清楚范例；本人解释；关参考实现与测试 | 题解后学习或提示后完成，不记为独立想出 |
| 旧题复现、码力 | 闭卷回忆模型；从空白重写；编译、测边界；修一类错误 | 旧题、是否独立、实现与调试用时 |
| 独立思维、迁移 | 不看算法标签；复述约束；小例子与朴素解；找性质；证明、实现与验证 | 是否真正陌生、提示级别、关键思路由谁提出 |
| 模拟比赛 | 按本场规则限时独立做题；保存原提交；评分后还原决策并订正 | 实际得分、时间线、完整解、部分分和主要瓶颈 |

看知识地图时可以了解后续用途，做题时仍检查前置。不按年级、题单颜色或历史 AC 直接判断阶段。

以动态规划为例，入门先解释状态、转移、初值、计算顺序与答案位置，再说明状态信息为何足够、分类是否覆盖且不重漏、复杂度为何符合约束。可从小规模计数到基础最优化与二维，再按课程进入背包、区间或树形模型。它是可分支路线，不是所有人必须照走的固定顺序。

出现实现问题，先保留失败程序，缩小反例；核对初始化、循环依赖、边界与类型。样例通过只是有限证据，适合时补暴力或小数据验证。没有运行就写未运行，没有 OJ 结果就不写 AC。

少量候选题可分为“待筛选、待理解、已有本人分析待实现”。初始只保留当前专题的几个任务，避免大量切换。所谓“学一例、试一题、连续独立练习”可作某类弱题强化，不规定每个算法必须刷固定四题。

## 5. 听讲、错题与求助

听讲前写出最想弄清的一步；过程中预测下一步、核对推理连接。听完能复述多少，随后能独立做多少，分别验证。

错题保留来源、自己的错误答案或关键步骤、首要原因、正确思路、关键条件、失败例子与下次复测。能写在原卷上就不必整题重抄。猜对但理由不清的题也纳入检查。

求助时带上已经尝试的模型或步骤，指出卡点。收到讲解后合上参考再做；“已问过”不能自动勾掉复习任务。

## 6. AI 辅助：提供反馈，留下无辅助表现

AI 可以解释概念、给分级提示、检查推理、找反例、批改表达和整理记录。学习者只要提示时不提前给完整结论；明确要完整解答时可以讲，但标明帮助程度。

先尝试、请求针对帮助、核对关键依据、关闭 AI 重做，再用延迟任务检查。完全缺基础时可以直接接受教学，不把“先尝试”变成无意义的苦耗。

AI 写出的分析、修好的程序、助手运行的评测，都是助手产物。本人能否解释、独立重建和迁移，要另外观察。研究讨论见 [来源 R4](sources.md#r4-ai-辅助与无辅助表现)。

## 7. 收工和跨设备继续

收工只留下：本次目标、实际作答、帮助程度、真实验证、未完成项、下一步和复测。看 [学习记录模板](../assets/session.md)。

另一台设备先读接续入口，再读最新记录和下一步；路径优先相对当前资料库。新反馈优先于旧日期安排。某任务没有完成，就写从哪个步骤继续，不把整批欠账搬到明天。看 [接续模板](../assets/handoff.md)。

提醒、日历、Git 同步和公开发布是独立操作，不能因为采用学习方法就自动执行。
