# 能力证据与指标

本页是便于实践判断的工作约定，不是标准化测评量表。未知保持未知，不用“没有看到证据”推断“完全不会”。

## 1. 将发生过的事分开记录

| 已发生的事 | 可以说明 | 还不能说明 |
|---|---|---|
| 看过讲解、收到 AI 答案 | 接触过该内容 | 本人能解释或独立完成 |
| 当堂答对一个数值或填空 | 这一项作答正确 | 完整过程、证明、实现和迁移都正确 |
| 提示后完成 | 在该帮助程度下能完成 | 无提示独立解决 |
| 从空白完成旧题并验证 | 该题或模型的复现证据 | 完全陌生题的独立发现 |
| 延迟无辅助重做成功 | 对该任务的保留证据 | 所有相关题都已稳定掌握 |
| 无标签新变式中独立完成 | 有对应的识别与迁移证据 | 跨难度、跨情境普遍成立 |
| 助手修正并运行通过 | 助手版本通过对应检查 | 学习者本人已经实现和验证 |

## 2. 掌握度 0—4

| 级别 | 含义 | 判断条件 |
|---|---|---|
| 0 | 未接触 | 有明确自述或诊断支持，不能仅凭资料缺失填写 |
| 1 | 能辨认 | 能说出用途或识别关键步骤 |
| 2 | 有提示能完成 | 能在已记录的帮助下完成主要推理、表达或实现 |
| 3 | 独立可用 | 陌生同类任务中独立解释、完成并检查，且有成功的延迟复测 |
| 4 | 稳定迁移 | 陌生综合任务中独立选方法、给依据、完成并多次复现 |

程序题还需从空白实现及关键边界验证。其他学科按题目要求检查条件、推导、单位、材料依据与表达。等级是摘要，不能替代具体证据；不同专题单独判断，不给整个人贴统一等级。

未完成某次复测时标明待测。一次成功只支持相应范围，不要求所有人通过机械固定题量才能学习下一层。

## 3. 六类首要卡点

- **K 知识**：概念、词义、定理、语法或算法缺口。
- **M 建模**：条件没有转成合适关系、状态、图或解释框架。
- **I 实现或表达**：思路清楚，计算、代码、步骤或语言没有正确落地。
- **B 边界或条件**：最小规模、特殊情况、适用范围、单位、溢出等遗漏。
- **V 验证**：未核对依据、关键测试、材料出处或最终输出。
- **T 时间策略**：过久停滞、答题顺序、订正与提交时间安排失衡。

每题选一个首要原因，其他问题简记备注。实际得分符合当时能力或主动取舍时如实写，不把所有失分统称粗心。分类用于选择下一步，不是标准诊断。

## 4. 个人方法效果看什么

| 指标 | 怎样计算或记录 | 容易误读的地方 |
|---|---|---|
| 无提示正确率 | 无提示独立正确任务数 / 实际尝试任务数；保留如 `2/3` 的原始计数 | 混入看过解法的题、小样本只写百分比 |
| 延迟保留 | 每次记录间隔、结果、帮助、用时与是否同题 | 用当堂顺畅代替一周后结果 |
| 变式迁移 | 标明是否陌生、是否去掉方法标签；记录独立选模、完成与验证 | 改数值、同题重写都算陌生迁移 |
| 错误复发 | 同类错误的复发次数 / 有该检查机会的任务数，并保留定义 | 不同难度、不同机会数直接比较 |
| 任务用时 | 区分读题、建模、推导/编码、调试与检查 | 把坐得久当学得会，或省略测试后宣称更快 |
| 比赛或整卷表现 | 实际分数、条件、熟悉程度、完整解、可追回失分与时间线 | 用单场推测稳定分，将预期分写成实测 |

教学块和无提示测验分别统计。用过提示后再完成的任务记为提示后完成；想测新的无提示表现，应另安排延迟任务或陌生任务。对比时注明难度、范围、先前接触与允许工具。

没有原始数据就不生成指标。研究中的效应量不能换算成个人涨分百分比。连续几次相近条件的记录有助于观察趋势，仍不足以保证正式考试结果。

## 5. 复测间隔

已有词汇或课程安排时先沿用。需要新起点时，可从首次真实独立完成日起试行 D+1、D+3、D+7、D+14；它是管理用初始表，不是所有内容的最优间隔。教学接触、当堂练习和诊断当然也可发生在首次独立完成之前，分别记录即可。

失败就核对是遗忘、理解还是应用问题，必要时缩小任务、补反馈和缩短下一间隔。稳定后可以延长。临近考试时按实际目标调整，不能为了凑日期挤掉休息。

## 6. 最少记录哪些字段

任务与来源、用途、是否见过解法、本人原始表现、帮助程度、真实检查结果、首要卡点、下一步。需要判断方法效果时再增加用时、延迟复测与陌生变式，不要求每次填写所有字段。

使用 [学习记录](../assets/session.md) 或现有笔记。样例和空白模板中的字段不是完成结果；任何自动整理都须保留“未提交、未运行、未评测、待复测”的真实状态。
