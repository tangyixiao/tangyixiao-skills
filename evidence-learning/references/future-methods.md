# 未来学习与方法试验

初版：2026-10-14。这里是阶段原则和候选试验，**不是已经实施的计划、效果结论或确定的未来校历**。不预设选科、考试日期、竞赛晋级或升学结果。

## 1. 长期看阶段，近期用实际任务落实

| 阶段或情境 | 学习重点 | 进入下一步看什么 |
|---|---|---|
| 高一与基础重建 | 跟稳课内；建立概念、条件与典型模型；补关键前置 | 已学内容能解释、独立完成，延迟后仍可使用 |
| 基础可用后的深化 | 连接单元，增加无标签变式、混合任务与规范表达 | 自己识别方法，解释选择理由，限时表现逐渐稳定 |
| 系统复习阶段 | 跟随学校范围梳理知识，按真实失分选专题 | 从“会某章题”转向整卷条件下可靠调用 |
| 考前稳定阶段 | 个人易错回查、熟悉流程、适量模拟、减少额外新材料 | 正常作息、答题节奏与提交检查可执行 |
| 阶段考试或竞赛之后 | 修一次真实损失，再决定新主线；恢复被压缩的必要任务 | 订正和延迟重做有结果，时间预算重新成立 |

这些阶段会重叠。不能因为日期到了就升级能力；也不用等全部基础完美才接触应用。长期只画方向，通常细化接下来一到两周；每周用少量时间根据作业、考试与复测调整。

文化课和信奥冲突时，先列学校固定要求、实际可支配时间及最常被挤掉的内容，再讨论投入取舍。不要凭旧停课表、一个目标分或创作者经历决定退出某条路线。

## 2. 方法候选：需要时选一种

以下包括已有方法的深化，以及尚未验证的候选。建议的分钟数、题量和观察窗口只是方便启动的参数，可以随现实缩小。

| 候选与适用条件 | 最小尝试 | 检验及停止条件 |
|---|---|---|
| **逐步撤去范例步骤**：完整例子能看懂，但仍离不开参考 | 下一次例题只补一个关键步骤，再独立完成小变式 | 看关闭参考后是否能解释；若猜步骤，退回概念与反馈 |
| **先尝试，再比较讲解**：已有相关基础，能提出不完整方案 | 留下两个想法或一个反例，再对照标准方法比较关键差异 | 看理解与后续迁移；完全无法启动或持续空转时转教学 |
| **PRIMM 式程序学习**：能读少量代码，独立实现仍困难 | 预测输出→运行→跟踪变量与解释→改一个条件→独立写同结构小程序 | 看最后能否离开范例独立写；若只复制，减少改动并补语义 |
| **无标签混合练习**：相关模型已分别能用 | 选少量已学模型的新题，先解释为何选该方法再做 | 看独立选模而非背题型；多个前置都不会时回专题补缺 |
| **对比题与反例**：公式会背，适用条件易混 | 比较只差一个关键条件的两题，构造使方法失效的小例子 | 看条件变化后能否调整；若反例只记答案，改问原因 |
| **按失败调整间隔**：已有复测结果，固定排表负担大 | 只给不稳内容安排更近复测，稳定内容延长间隔 | 看延迟保留与负担；遗忘加重时缩短并补理解 |
| **英语从辨认转向使用**：词表认得，语境或输出不稳 | 用少量到期词做辨义、短句或段落修改 | 看换语境后正确性；错词回到原语境，不靠机械加新词 |
| **短篇自我解释**：能算出答案，说不清理由 | 只回答“为什么这一步成立、依赖什么条件、换条件如何”中的一问 | 看解释与后续解题；长篇记录挤掉实践时缩短 |

前面几种方法有相关研究或教学资料；无标签混合、对比与个性化排表在本项目中的具体用法属于待检验设计。证据及外推限制见 [来源与边界](sources.md)。选题质量与前置条件比流程名字重要。

## 3. 用一个小试验决定保留什么

例：问题是“例题当堂会做，隔天转移不会解释”。可只尝试在范例后增加一分钟关键理由解释，其余练习保持近似。

1. 先记录现状：一组相近内容的无提示结果与实际时间；不为做对照故意放弃学校要求或必要反馈。
2. 选一种改变，写预期作用、适用前提和允许投入的预算。
3. 在若干个可比较学习块中使用，记录帮助程度、难度与是否见过解法。
4. 按预先写好的窗口做延迟复测与一个陌生变式。要观察一周后的结果，就等结果实际到来后再总结。
5. 比较无辅助表现与负担。改善明显且可持续时暂时保留；表现不变或更差就查任务难度、方法执行和评价条件，再决定调整或停止。

一次只改变一种主要做法，便于理解变化。个人前后比较仍受题目难度、原有基础、老师讲解与状态影响，只支持实践取舍，不能据此宣称因果关系或推广给所有人。

可以用 [方法试验模板](../assets/experiment.md)。不要为了试验建立复杂数据库；已有学习记录足够时直接增加几行。

## 4. 什么时候缩小或停止

- 连续任务都不能启动：补前置或换小例子，不继续硬推高阶内容。
- 当堂顺畅但延迟表现没有改善：增加回忆与反馈，减少一次性新内容。
- 同题会做，换题不会：检查是否只记住答案，增加条件比较与无标签任务。
- 记录、工具或打卡挤掉实际学习：保留最少的证据字段，停止多余维护。
- 影响休息或必做任务：缩小额外试验，不用熬夜完成方法清单。
- 没有可比较的结果：写证据不足，保留原始记录，不编结论。

## 5. 将来怎样更新这个项目

新增方法时写清它解决什么问题、谁适合、具体怎样试、什么结果支持继续、什么情况要停，以及来源属于研究还是经验。新增个人结果前先匿名化并征得相应公开授权。

未来可以根据真实复测改进模板、补学科示例或进一步核对研究。这里没有承诺自动监控研究、自动上传记录或定期运行 AI；需要这些功能时另行明确范围与授权。
